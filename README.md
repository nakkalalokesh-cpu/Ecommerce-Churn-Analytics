# E-Commerce Customer Behavior & Churn Analytics

## 📌 Project Overview
Analysis of 50,000 e-commerce customers to understand
churn behavior, revenue patterns and customer segments
using Python, SQL and Power BI.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- MySQL
- Power BI

## 📊 Dataset
- 50,000 customers
- 25 features
- Source: E-Commerce Customer Churn Dataset

## 🔑 Key Findings
- 28.9% churn rate — 14,450 customers lost
- USA generates highest revenue — $24.9 Million
- Champions segment has highest avg revenue — $2,519
- Low login frequency is top churn indicator
- High cart abandonment leads to churn

## 📁 Project Structure
- Data/ — Raw and cleaned datasets
- Notebook/ — Jupyter notebook with Python code
- Screenshots/SQL/ — SQL query results
- Screenshots/PowerBI/ — Dashboard screenshots
